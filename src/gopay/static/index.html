Bienvenue sur Go Pay

Envoyez de l'argent à n'importe quel numéro au Sénégal. Le bénéficiaire le retire en espèces chez un agent, avec un code à 6 chiffres.

  1. 1Ouvrez votre wallet avec votre nom et votre numéro.
  2. 2Déposez puis envoyez : les frais sont de 1 %, 50 FCFA au moins.
  3. 3Transmettez le code : le bénéficiaire retire l'argent chez un agent.
